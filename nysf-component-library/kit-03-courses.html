About the course

Learn to turn complex climate data into clear, compelling stories that move audiences to action. This course blends scientific rigour with practical communication skills.

What you'll learn

  • ✓ Read and interpret climate datasets
  • ✓ Build clear data visualisations
  • ✓ Write for non-expert audiences
  • ✓ Present with confidence
  • ✓ Avoid common misconceptions
  • ✓ Tell stories that drive change

Requirements

  • ✓ No prior science background needed
