Student Staff Leadership Program (SSLP)

Come back, train up, and help run NYSF for the next cohort.

Apply now

About the program

Each year, selected Year 12 Program participants take part in the Student Staff Leadership Program. They develop leadership, teamwork and self-awareness, then return the following January to help deliver the NYSF Year 12 Program as Student Staff Leaders, known as Staffies. It’s the clearest expression of NYSF being run by youth, for youth.

What’s included

  • ✓ Professional leadership training
  • ✓ Hands-on event facilitation experience
  • ✓ Work-ready skills training
  • ✓ Youth-led mentoring program
  • ✓ An ongoing alumni community

Who it’s for

Selected NYSF Year 12 Program participants, chosen through an application process.

In their words

“Being a NYSF Staffie was the challenge I’d been waiting for my entire life.”
Bailey, NYSF 2017 Student Staff
