# NYSF Website Redesign — Prototype

A static, fully navigable redesign prototype for the National Youth Science Forum (NYSF), built entirely from a reusable, brand-styled component library.

## View it

- **Live site:** _add your GitHub Pages URL here once published_
- **Entry point:** the root URL redirects to `prototype/index.html` (the client review console), which links to every page and to the component library.

## What's in here

- `prototype/` — the complete clickable site: homepage, audience hubs, programs, about pages, impact, resources, article, contact, donate, and the review console (`index.html`).
- `nysf-component-library/` — the theme-native module kit (kit-01 to kit-07) every page is assembled from.
- `assets/` — images and logo used by the site.
- `index.html` (root) — redirect to the prototype.
